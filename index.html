Core Features

专为平板打磨的工程级利器

告别玩具级代码查看器，HelmCode 赋予 iPad 真正的全功能开发与 AI 编排能力。

移动优先的纯原生体验

基于 Swift 与 SwiftUI 深度构建。无论是 iPadOS 多任务分栏、触控拖拽，还是 Magic Keyboard 键盘快捷键（⌘P, ⌘O, ⌘J），每一个交互都丝滑顺畅、原生贴心。

Pure SwiftUI SplitView 键盘快捷键

CodeMirror 6 极速编辑

专业级现代代码编辑内核，内置数十种开发语言的离线语法高亮（Swift, TypeScript, Go, Python, Rust, Dockerfile 等）。毫秒级首字响应，支持 OneDark 主题与多光标编辑。

CodeMirror 6 离线语法包 OneDark

Agent Commander 领航员

深度集成 ACP (Agent Client Protocol) 协议。支持 OpenCode、Claude、Codex、Cursor、Grok 等多种大模型。使用 / 快捷触发技能，使用 @ 引用文件，由 AI 驱动代码重构与自动化生成。

ACP 协议 多模型路由 智能 Diff 预览

高性能 WebSocket VFS

基于 JSON-RPC over WebSocket 的远程虚拟文件系统。无缝加载万级海量代码仓库，支持大文件分块流式打开、软热重载以及直接在 iPad 上进行 Git 分支切换与变动审查。

WebSocket RPC Git 模型 双向热同步

WebSSH 全功能终端 (⌘J)

随时按下 ⌘J 瞬间滑出内置终端。基于 xterm.js 打造的真实 PTY 会话，完整支持 Bash, Zsh, Vim, Tmux，随意执行 npm build、cargo test 或 docker 容器管理。

xterm.js PTY 常驻会话 独立面板

安全隐私与 100% 自托管

你的代码和密钥只属于你。runner-core 引擎开源并完全支持在个人服务器、本地工作站或内网 NAS 自托管。点对点安全配对令牌存储于系统 Keychain，零数据上云泄露。

System Architecture

分层解耦的云端与端侧协同

将沉重的编译算力与模型调度交给后端沙盒，端侧专注于极致的原生交互体验。

Quick Start

三步快速开启使用

仅需数分钟，即可在本地服务器或云端 VPS 启动后端，并在 iPad 上建立连接。

Step 1

启动 runner-core 容器

在任意安装了 Docker 的服务器或电脑上，使用官方 Compose 启动沙盒后端服务：

docker run -d -p 18080:8080 \
  -v $PWD:/app/workspace \
  helmcode/runner-core:latest
Step 2

在 iPad 上配对设备

打开 iPad 上的 HelmCode，点击「Open Project → Self-hosted」，输入服务器地址与配对安全码：

URL: http://your-server-ip:18080
Setup Code: SDCN-9XZS
Step 3

开启高效 AI 编程

连接成功后，万级文件树秒级呈现。按下 ⌘J 唤出终端，或在 Commander 输入提示词由 AI 辅助开发：

/test 运行单元测试
@server.ts 请为该接口增加限流中间件
