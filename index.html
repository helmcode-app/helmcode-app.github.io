Quick Start

Up and Running in 3 Steps

Spin up the runner daemon on your server or laptop, then pair your iPad in minutes.

Step 1

Run runner-core Container

Start the headless runner daemon on any machine with Docker installed:

docker run -d -p 18080:8080 \
  -v $PWD:/app/workspace \
  helmcode/runner-core:latest
Step 2

Pair Your Device

Open HelmCode on iPad, tap 「Add Runner」, then enter your runner URL and pairing setup code:

URL: http://your-server-ip:18080
Setup Code: SDCN-9XZS
Step 3

Code with AI Velocity

Your remote files render instantly. Hit ⌘J for terminal or compose prompts in Agent Commander:

/test Run test suite
@server.ts Add rate-limiting middleware to this handler

HelmCode uses a pure native SwiftUI shell with an offline CodeMirror 6 engine, communicating with your runner-core daemon over WebSocket. HelmCode implements the open ACP (Agent Client Protocol) standard, supporting harnesses including OpenCode, Claude, Codex, Cursor, and Grok. Configure your API keys in your runner or app settings to seamlessly switch models right inside the Agent Commander composer.
